# 第1讲 函数极限与连续

> **对应拆分 PDF**：`分章PDF/第01讲_函数极限与连续.pdf`（PDF 页 7–81，书内页 1–75，75 页）
> **教材标注**：考题＝计算函数极限｜题型＝选择题、填空题、解答题｜**重难点＝①洛必达法则 ②泰勒公式**
> **数一适用**：全讲必考，★★★★★（高数第一大基础，后续所有讲的工具）

---

## 一、核心知识点

1. **函数**：定义域与对应法则；有界性、单调性、奇偶性、周期性；复合函数、分段函数、反函数、隐函数；基本初等函数与初等函数。
2. **极限概念**：$\varepsilon$-$\delta$ 定义；左极限 $f(x_0^-)$、右极限 $f(x_0^+)$；$\lim\limits_{x\to x_0}f(x)=A \iff$ 左右极限都存在且相等。$x\to\infty$ 需分 $+\infty$ 与 $-\infty$（涉及 $e^x,\arctan x,|x|,x^\alpha$ 时）。
3. **极限性质**：唯一性、局部有界性、局部保号性（及逆用：若极限 $>0$ 则邻域内 $f>0$）、四则运算法则（每部分极限须存在）、复合函数极限运算法则。
4. **无穷小与无穷大**：无穷小阶的比较（高阶、低阶、同阶、等价、$k$ 阶）；等价无穷小替换定理；无穷大与无穷小的倒数关系。
5. **求极限工具**：两个重要极限、两个准则（夹逼、单调有界，详见第2讲）、等价无穷小、洛必达法则、泰勒公式、导数定义、定积分定义、拉格朗日中值定理。
6. **连续性**：$\lim\limits_{\Delta x\to0}\Delta y=0$；左/右连续；间断点分类（第一类：可去、跳跃；第二类：无穷、振荡）；闭区间上连续函数的有界性、最值定理、介值定理、零点定理；初等函数在定义区间内连续。

## 二、公式定理

| 类别 | 内容 |
|---|---|
| 两个重要极限 | $\lim\limits_{x\to0}\dfrac{\sin x}{x}=1$，$\lim\limits_{x\to\infty}\left(1+\dfrac1x\right)^x=\lim\limits_{x\to0}(1+x)^{1/x}=e$ |
| 常用等价无穷小（$x\to0$） | $\sin x\sim x$，$\tan x\sim x$，$\arcsin x\sim x$，$\arctan x\sim x$，$\ln(1+x)\sim x$，$e^x-1\sim x$，$1-\cos x\sim \frac{x^2}{2}$，$(1+x)^\alpha-1\sim \alpha x$，$a^x-1\sim x\ln a$ |
| 高阶等价（差型，必背） | $x-\sin x\sim\dfrac{x^3}{6}$，$\tan x-x\sim\dfrac{x^3}{3}$，$x-\arctan x\sim\dfrac{x^3}{3}$，$\arcsin x-x\sim\dfrac{x^3}{6}$，$x-\ln(1+x)\sim\dfrac{x^2}{2}$，$\tan x-\sin x\sim\dfrac{x^3}{2}$ |
| 幂指型 | $1^\infty$ 型：$\lim u^v=e^{\lim v(u-1)}$（$u\to1,\ v\to\infty$）；一般 $u^v=e^{v\ln u}$ |
| 泰勒（佩亚诺余项） | $e^x=1+x+\frac{x^2}{2!}+\cdots+\frac{x^n}{n!}+o(x^n)$；$\sin x=x-\frac{x^3}{3!}+\frac{x^5}{5!}-\cdots$；$\cos x=1-\frac{x^2}{2!}+\frac{x^4}{4!}-\cdots$；$\ln(1+x)=x-\frac{x^2}{2}+\frac{x^3}{3}-\cdots$；$(1+x)^\alpha=1+\alpha x+\frac{\alpha(\alpha-1)}{2!}x^2+\cdots$；$\frac1{1-x}=1+x+x^2+\cdots$ |
| 洛必达法则 | 仅适用于 $\frac00,\frac\infty\infty$；要求 $\lim\frac{f'}{g'}$ 存在（或 $\infty$）；可连续使用，每次先化简、先验证 |
| 无穷小阶 | 若 $\lim\dfrac{\beta}{\alpha^k}=c\neq0$，则 $\beta$ 是 $\alpha$ 的 $k$ 阶无穷小 |
| 间断点 | 左右极限都存在＝第一类（相等→可去，不等→跳跃）；至少一个不存在或为 $\infty$＝第二类（无穷、振荡） |

## 三、典型题型与解题思路

1. **$\frac00$ 型极限**：先提取公因式、等价无穷小**乘除因子**替换化简 → 若分子分母为多项式型差，用泰勒展开到同阶 → 最后才用洛必达。口诀：**先化简、后替换、再展开、末洛必达**。
2. **$\infty-\infty$ / $0\cdot\infty$**：通分、有理化、倒代换 $t=\frac1x$、提最高阶公因子，化为 $\frac00$ 或 $\frac\infty\infty$。
3. **$1^\infty,\ \infty^0,\ 0^0$**：取对数写成 $e^{v\ln u}$，指数部分按 $\frac00$ 处理；$1^\infty$ 直接用 $e^{\lim v(u-1)}$ 最快。
4. **含参数极限**：比较分子分母的阶，对参数（如 $a,b$、指数 $\alpha$）分段讨论；由"极限存在且非零"反定参数值。
5. **已知极限反求参数 / 反求函数**：把已知式按泰勒展开，令低阶项系数为零、主项系数匹配。
6. **分段函数分界点**：必须用左右极限分别计算，切忌直接代入。
7. **间断点判别**：先找可疑点（分母为零、分段点、无定义点、$\tan$/$\ln$ 边界），逐个算左右极限再分类。
8. **证明连续 / 存在零点 / 存在 $\xi$**：构造辅助函数，用零点定理、介值定理或最值定理；含 $f'(\xi)$ 的等式留到第6讲中值定理。
9. **数列极限转函数极限**：海涅定理（$\lim\limits_{x\to x_0}f(x)=A\iff$ 对任意 $x_n\to x_0$ 有 $f(x_n)\to A$），常用于证明**极限不存在**（取两个不同子列）。

## 四、复习重点（★ 为教材/真题高频）

- ★★★ 洛必达法则与泰勒公式（教材明确列为重难点）：泰勒要能"按需定阶"，分子分母展开到**相同阶**为止。
- ★★★ 等价无穷小替换：牢记乘除可换、加减不可换；差型极限必须记上面的高阶等价表。
- ★★ 幂指函数与 $1^\infty$ 型，$\infty-\infty$ 的化归。
- ★★ 间断点分类与含参讨论（选择题高频）。
- ★ 函数性态（奇偶、周期、有界）与复合函数、反函数的表达。

## 五、易错点

1. **在加减中滥用等价无穷小**：$\lim\limits_{x\to0}\dfrac{\sin x-x}{x^3}$ 不能把 $\sin x$ 换成 $x$ 得 $0$，正确为 $-\frac16$。
2. **洛必达未验条件**：对 $\frac{1}{0}$、$\frac{\infty}{0}$、$\frac{0}{\infty}$ 误用；$\lim\frac{f'}{g'}$ 不存在时不能断言原极限不存在（如 $x+\sin x$ 型）。
3. **泰勒阶数不足**：分子是 $x^3$ 阶时只展开到 $x^2$，得到"极限为 0"的错误结论。
4. **$1^\infty$ 直接代入得 1**；忽略 $u\to1$ 前提；$\infty^0,0^0$ 未取对数。
5. **只算单侧**：$x\to0$ 时 $e^{1/x}$、$\arctan\frac1x$、$\frac{|x|}{x}$ 必须分左右；$x\to\infty$ 时 $e^x$、$x^\alpha$（非整数 $\alpha$）在 $-\infty$ 可能无定义。
6. **间断点类型混淆**：可去与跳跃都属第一类；$\sin\frac1x$ 型振荡属第二类；只补定义不叫"连续"。
7. **由 $\lim f(x)=A>0$ 推不出 $f(x)>0$ 处处成立**，只能得去心邻域内成立（局部保号）。
8. **复合函数极限**：内层趋于 $u_0$ 但外层在 $u_0$ 不连续时，不能直接换序求极限。

# 第2讲 数列极限

> **对应拆分 PDF**：`分章PDF/第02讲_数列极限.pdf`（PDF 页 82–104，书内页 76–98，23 页）
> **教材标注**：考题＝证明数列极限的存在性｜题型＝选择、填空、解答｜**重难点＝①海涅定理的应用 ②通过放缩利用夹逼准则求极限 ③单调有界准则证明极限存在**
> **数一适用**：全讲必考，★★★★（解答题证明题高频）

---

## 一、核心知识点

1. **定义**：$\lim\limits_{n\to\infty}x_n=A \iff \forall\varepsilon>0,\ \exists N,\ n>N \Rightarrow |x_n-A|<\varepsilon$。用于**证明**极限，不用于计算。
2. **性质**：唯一性、有界性（收敛必有界，反之不真）、保号性、四则运算、子列一致性（收敛数列任一子列收敛到同一极限）。
3. **两个准则**：夹逼准则（放缩后两端同极限）、单调有界准则（单调递增有上界 / 递减有下界 ⇒ 收敛）。
4. **海涅定理（归结原则）**：$\lim\limits_{x\to x_0}f(x)=A \iff$ 对任意满足 $x_n\to x_0,\ x_n\neq x_0$ 的数列都有 $f(x_n)\to A$；常用来**证明函数极限不存在**（构造两个子列得到不同极限）。
5. **定积分定义法**：$\lim\limits_{n\to\infty}\frac1n\sum\limits_{k=1}^{n}f\!\left(\frac{k}{n}\right)=\int_0^1 f(x)\,dx$，把和式极限化为定积分。
6. **递推数列** $x_{n+1}=f(x_n)$：证有界 → 证单调 → 设 $\lim x_n=A$ 解 $A=f(A)$ → 结合有界性/单调性排除多余根。
7. **常见结论**：$\sqrt[n]{a}=1(a>0)$，$\sqrt[n]{n}=1$，$\lim q^n=0(|q|<1)$，$\lim\frac{n^k}{a^n}=0(a>1)$，$\lim\frac{a^n}{n!}=0$，$\lim\frac{\ln n}{n}=0$；Stirling 公式 $n!\sim\sqrt{2\pi n}\left(\frac ne\right)^n$。

## 二、公式定理

| 工具 | 表达与要点 |
|---|---|
| 夹逼准则 | $y_n\le x_n\le z_n$，$\lim y_n=\lim z_n=A \Rightarrow \lim x_n=A$；关键是**放缩到同极限** |
| 单调有界准则 | 单调＋有界 ⇒ 收敛；只需证明有界与单调，不必先猜出极限 |
| 定积分定义 | $\frac1n\sum f(k/n)\to\int_0^1f$，或 $\frac{b-a}{n}\sum f\big(a+\frac{k(b-a)}n\big)\to\int_a^b f$ |
| 海涅定理 | 函数极限 ⇄ 数列极限；证不存在时取 $x_n=\frac1{2n\pi},\ y_n=\frac1{(2n+1/2)\pi}$ 等 |
| 均值型 | $\lim\sqrt[n]{a_1^n+\cdots+a_m^n}=\max\{a_i\}$（$a_i>0$），由夹逼得 |
| 递推极限 | $A=f(A)$ 的根只是**候选**，必须验证收敛性与根所在区间 |

## 三、典型题型与解题思路

1. **$n$ 项和的极限**：$\sum\frac{k}{n^2+k^2}$、$\sum\frac{1}{\sqrt{n^2+k^2}}$ 等 → 优先尝试**定积分定义**；不能写成 $\frac1n\sum f(k/n)$ 的用夹逼放缩。
2. **夹逼放缩**：把分母统一放大/缩小到只与 $n$ 有关，如 $\frac{n}{\sqrt{n^2+n}}\le\sum_{k=1}^n\frac1{\sqrt{n^2+k}}\le\frac{n}{\sqrt{n^2+1}}$；注意放缩不能改变主阶。
3. **递推数列证明存在**：数学归纳法证 $0<x_n<M$ → 作差 $x_{n+1}-x_n$ 或作商判单调 → 解方程取根。经典：$x_{n+1}=\sqrt{2+x_n}$、$x_{n+1}=\frac12(x_n+\frac a{x_n})$。
4. **由递推式求和/求极限**：先取对数或倒数化为线性递推；或利用 $x_{n+1}-A=\lambda(x_n-A)$ 型压缩。
5. **含 $n!$、$n^n$、组合数**：Stirling 公式 + 比值判别思想。
6. **证明函数极限不存在**：用海涅定理取两个子列（振荡因子 $\sin\frac1x$、$\sin x$ 在 $\infty$ 处）。
7. **抽象数列**：由 $x_n\to A$ 推出 $\frac{x_1+\cdots+x_n}{n}\to A$（Cesàro 平均）、$\sqrt[n]{x_1\cdots x_n}\to A$（$x_i>0$）。

## 四、复习重点

- ★★★ 单调有界准则证明极限存在（解答题常考，需完整写"有界性＋单调性"两步）。
- ★★★ 夹逼准则中的**放缩尺度**与定积分定义求和式极限。
- ★★ 海涅定理在"函数极限不存在/数列极限不存在"证明中的应用。
- ★★ 递推数列求极限与 $A=f(A)$ 根的取舍。

## 五、易错点

1. **只解 $A=f(A)$ 不证收敛**：这是最典型的失分点，必须先证极限存在。
2. **放缩过粗**：两端极限不相等，或放缩后主阶被改变（如把 $\frac{k}{n}$ 直接丢掉）。
3. **误用四则运算**：$\lim(x_n+y_n)$ 存在不能反推各自存在；$\infty-\infty$、$0\cdot\infty$ 未定式不能直接拆。
4. **定积分定义写错形式**：漏掉 $\frac1n$、把 $\sum f(k/n)$ 写成 $\int_0^n$、或 $f$ 的自变量弄错。
5. **收敛 ⇒ 有界，有界 ⇏ 收敛**：如 $(-1)^n$；振荡数列不能取"极限"。
6. **忽略 $x_n\neq x_0$**：海涅定理要求数列不取到极限点本身，否则外层可能无定义。
7. **单调性方向判错**：用 $\frac{x_{n+1}}{x_n}$ 判单调时须先证 $x_n>0$。

# 第3讲 一元函数微分学的概念

> **对应拆分 PDF**：`分章PDF/第03讲_一元函数微分学的概念.pdf`（PDF 页 105–124，书内页 99–118，20 页）
> **教材标注**：考题＝一元函数微分学的概念｜题型＝选择题、填空题｜**重难点＝①高阶导数的计算 ②导数几何意义的应用 ③可导充要条件的应用**
> **数一适用**：全讲必考，★★★★（选择题"概念辨析"主战场）

---

## 一、核心知识点

1. **导数定义**：$f'(x_0)=\lim\limits_{\Delta x\to0}\dfrac{f(x_0+\Delta x)-f(x_0)}{\Delta x}=\lim\limits_{x\to x_0}\dfrac{f(x)-f(x_0)}{x-x_0}$；常用变形 $\lim\limits_{h\to0}\dfrac{f(x_0+ah)-f(x_0-bh)}{(a+b)h}=f'(x_0)$。
2. **单侧导数**：$f'_-(x_0),f'_+(x_0)$；**可导 $\iff$ 左右导数都存在且相等**。
3. **可导与连续**：可导 $\Rightarrow$ 连续，连续 $\nRightarrow$ 可导（$y=|x|$）；$f$ 在 $x_0$ 可导 $\nRightarrow f'$ 在 $x_0$ 连续。
4. **几何意义**：$f'(x_0)$ 为切线斜率；切线 $y-f(x_0)=f'(x_0)(x-x_0)$；法线 $y-f(x_0)=-\frac{1}{f'(x_0)}(x-x_0)$（$f'=0$ 时法线为竖直线 $x=x_0$）。
5. **微分**：$\Delta y=f'(x)\Delta x+o(\Delta x)$，$dy=f'(x)dx$；**一元函数可微 $\iff$ 可导**；一阶微分形式不变性。
6. **高阶导数**：$f^{(n)}$；莱布尼茨公式；常用 $n$ 阶导数公式；由泰勒/幂级数系数反求 $f^{(n)}(0)$。
7. **可导性判定**：$|f(x)|$ 在 $f(x_0)=0$ 处的可导条件、$(x-x_0)^\alpha$ 型、含绝对值与分段点。

## 二、公式定理

| 类别 | 内容 |
|---|---|
| 导数定义变体 | $\lim\limits_{h\to0}\frac{f(x_0+mh)-f(x_0+nh)}{(m-n)h}=f'(x_0)$；分子必须是"函数值之差"，分母是对应自变量之差 |
| 莱布尼茨公式 | $(uv)^{(n)}=\sum\limits_{k=0}^n C_n^k u^{(k)}v^{(n-k)}$ |
| 常用 $n$ 阶导 | $(e^{ax})^{(n)}=a^ne^{ax}$；$(\sin x)^{(n)}=\sin(x+\frac{n\pi}{2})$；$(\cos x)^{(n)}=\cos(x+\frac{n\pi}{2})$；$(\ln(1+x))^{(n)}=\frac{(-1)^{n-1}(n-1)!}{(1+x)^n}$；$\left(\frac1{x+a}\right)^{(n)}=\frac{(-1)^n n!}{(x+a)^{n+1}}$；$(x^m)^{(n)}=\frac{m!}{(m-n)!}x^{m-n}$ |
| 绝对值可导 | $g(x)=|f(x)|$ 在 $f(x_0)=0$ 处：若 $f'(x_0)=0$ 则可导且 $g'(x_0)=0$；若 $f'(x_0)\neq0$ 则不可导（尖点） |
| 幂型可导 | $f(x)=(x-x_0)^\alpha|x-x_0|$ 类：$\alpha>1$ 可导，$\alpha=1$ 需分左右，$0<\alpha<1$ 导数无穷 |
| 奇偶性求导 | 奇函数的导数是偶函数，偶函数的导数是奇函数；周期函数的导数同周期 |
| 泰勒系数 | 若 $f(x)=\sum a_n x^n$，则 $f^{(n)}(0)=n!\,a_n$ |

## 三、典型题型与解题思路

1. **用定义求导 / 由极限求 $f'(x_0)$**：把所给极限凑成 $\frac{f(x_0+\square)-f(x_0)}{\square}$ 形式，注意系数配平；若只给 $\lim\frac{f(x_0+h)-f(x_0-h)}{h}$ 存在，**不能**推出可导。
2. **抽象函数可导性判断**：已知 $f$ 在 $x_0$ 连续/可导，判断 $|f|$、$f\cdot g$、$f(g(x))$ 的可导性 → 一律回到定义写差商，必要时举反例 $f(x)=|x|$、$x^2\sin\frac1x$。
3. **分段函数分界点**：必须用定义算左右导数，不能用求导公式直接代（公式只在开区间内有效）。
4. **导数几何意义**：求切线/法线、公切线、切线与坐标轴围成面积、已知切线反求参数；注意"在 $x_0$ 处的切线"与"过 $x_0$ 的切线"不同。
5. **高阶导数**：优先用莱布尼茨（一项为多项式时最省事）；或拆成部分分式 / 用 $\sin^{2}x=\frac{1-\cos2x}{2}$ 降次；或用泰勒展开比对系数求 $f^{(n)}(0)$。
6. **导数与极限综合**：$\lim\limits_{x\to0}\frac{f(x)}{x}=A$ 且 $f$ 连续 ⇒ $f(0)=0,\ f'(0)=A$。

## 四、复习重点

- ★★★ 可导的充要条件（教材重难点）：左右导数、可导与连续、绝对值函数可导性。
- ★★★ 高阶导数计算（莱布尼茨 + 常用公式 + 泰勒系数法）。
- ★★ 导数几何意义：切线、法线、公切线与参数反求。
- ★★ 用定义处理抽象函数 / 分段点（选择题高频）。

## 五、易错点

1. **"$\lim\frac{f(x_0+h)-f(x_0-h)}{2h}$ 存在 ⇒ 可导"是错的**，对称差商存在只是必要条件（$f=|x|$ 在 0 处即为反例）。
2. **$f'(x_0)$ 存在 $\neq$ $\lim\limits_{x\to x_0}f'(x)$ 存在**；导函数可以不连续（$x^2\sin\frac1x$）。
3. **分段点直接套求导公式**；或分别求导后取极限当作该点导数（须连续且导数极限存在才可用）。
4. **$|f(x)|$、$\max\{f,g\}$ 的可导条件**记反；忽略 $f(x_0)=0$ 且 $f'(x_0)=0$ 时可导。
5. **法线斜率写成 $-f'(x_0)$**；$f'(x_0)=0$ 时法线竖直、$f'(x_0)=\infty$ 时切线竖直。
6. **莱布尼茨公式项数/组合数写错**；对 $x^m$ 求 $n>m$ 阶导数应为 0。
7. **"过点的切线"漏解**：设切点为 $(t,f(t))$ 列方程，可能有多条切线。
