# 考研数学一 · 高等数学（张宇《基础30讲》高数分册）复习资料

本仓库由《考研数学基础30讲·高等数学分册》（586 页扫描版）自动拆分整理而成，包含分讲 PDF 与配套复习提纲。

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `分章PDF/` | 按「讲」拆分的 25 份 PDF（前置页 + 18 讲 + 6 附录），未压缩降采样，公式清晰 |
| `分章PDF/_拆分清单.csv` | 每份 PDF 的书内页码、PDF 页码、页数、体积与校验结果 |
| `考研数学一复习资料/` | 逐讲复习提纲（markdown）+ 浏览器阅读版 HTML |
| `split_chapters.py` | 拆分脚本：可从原始 PDF 一键重新生成分章文件 |
| `build_outline.py` | 提纲生成脚本：可一键重建提纲文档 |

## 数学一适用性说明

- 第 7 讲：**只考**物理应用与相关变化率（经济应用数一不考）
- 第 12 讲：**只考**物理应用（经济应用数一不考）
- 第 13 讲：二元二阶泰勒公式（数一要求，数二数三不要求）
- 第 15 讲：差分方程部分数学一不作要求，可略
- 第 16 讲：含**傅里叶级数**（仅数一）
- 第 17、18 讲：整体**仅数学一**

## 重新生成

```bash
# 从原始 PDF 重新拆分（需 PyMuPDF）
python split_chapters.py

# 重建提纲文档
python build_outline.py
```

原始 PDF：`27张宇基础30讲（高数）.pdf`（353 MB，纯扫描图像，无文字层），体积较大故未纳入版本库。
